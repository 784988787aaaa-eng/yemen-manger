# Yemen Manager — خارطة التنفيذ ومعايير القبول

## قواعد عامة
- نفّذ مراحل صغيرة قابلة للبناء.
- بعد كل مرحلة: شغّل البناء والاختبارات المتاحة، وسجّل النتائج الفعلية.
- لا تنتقل بعد فشل حرج دون معالجة أو توثيق خطة عزل واضحة.
- لا تضف تبعيات تحتاج تنزيلًا عبر الإنترنت. افحص الكاش المحلي أولًا.

## P0 — تحقق المشروع والبناء
**المخرجات:** مشروع Android قابل للبناء، README، قائمة تبعيات، سجل قرارات.
**القبول:** نجاح بناء فعلي أو تقرير blocker محدد بالدليل؛ لا شيفرة زائدة غير لازمة.

## P1 — هيكل التطبيق والهوية
**المخرجات:** اسم Yemen Manager، تصميم أولي مستقل، Material 3، navigation، tokens، حالات تحميل/خطأ/فراغ، أساس RTL/LTR.
**القبول:** تشغيل التطبيق وفتح الشاشات الأساسية؛ اختبار أولي للعربية والإنجليزية؛ لا أزرار زائفة.

## P2 — نواة مدير الملفات
**المخرجات:** لوحتان مستقلتان، التنقل في المجلدات، عرض الملفات والمجلدات، تحديد، خصائص، مفضلة وسجل بسيط.
**القبول:** التنقل في كل لوحة مستقل؛ معالجة أخطاء الأذونات؛ SAF لا يعامل URI كمسار عادي.

## P3 — عمليات الملفات
**المخرجات:** إنشاء مجلد، إعادة تسمية، نسخ، نقل، حذف مع تأكيد، مركز عمليات.
**القبول:** حالات نجاح وفشل وإلغاء؛ عدم حذف المصدر عند النسخ؛ رسائل واضحة عند تعذر العملية؛ اختبار وجهات موجودة ونفاد مساحة.

## P4 — البحث والمعاينة والتحرير
**المخرجات:** بحث، معاينة نص، محرر نص، undo/redo مضبوط الحدود، حفظ آمن.
**القبول:** لا تجميد للواجهة؛ الترميز واضح؛ فشل الحفظ لا يتلف الأصل؛ اختبارات ملفات كبيرة نسبيًا.

## P5 — Hex وDiff
**المخرجات:** عارض Hex، بحث بايتات، تحرير مضبوط، مقارنة نصية/ثنائية.
**القبول:** offsets صحيحة، حدود الذاكرة واضحة، لا حفظ فوق الأصل دون تأكيد ومسار آمن.

## P6 — الأرشيفات
**المخرجات:** استعراض ZIP أولًا، استخراج انتقائي، إنشاء/إضافة مدعومة.
**القبول:** حماية Zip Slip، حدود لحجم التوسع، التعامل مع الأرشيف التالف والمشفر، اختبار الملفات الكبيرة.

## P7 — APK Read-Only Lab
**المخرجات:** ملخص APK، محتويات ZIP، عرض Manifest والموارد وملفات DEX عند دعم المحركات.
**القبول:** التحليل لا ينفذ المحتوى؛ أخطاء التنسيق واضحة؛ مخرجات اختبارات مرجعية.

## P8 — APK Editing / Rebuild / Signing
**المخرجات:** تعديل موارد محددة، إعادة بناء مدعومة، توقيع بمفتاح المستخدم، تحقق بعد البناء.
**القبول:** بيان تغييرات، الحفاظ على الأصل، التحقق من المخرجات، شرح أن تعديل الحزمة يبطل توقيعها الأصلي غالبًا.

## P9 — التطبيقات المثبتة والصلاحيات
**المخرجات:** بيانات التطبيقات التي يوفرها النظام، استخراج base/split APKs، مثبت النظام، مزودات اختيارية.
**القبول:** لا ادعاء صلاحيات غير متوفرة؛ لا دمج غير صحيح للحزم المقسمة؛ حالات رفض الصلاحية واضحة.

## P10 — الشبكة والإضافات
**المخرجات:** بروتوكولات اختيارية وخادم محلي مع إيقاف واضح، ثم API إضافات بعد استقرار النواة.
**القبول:** لا اتصالات تلقائية؛ مصادقة مناسبة؛ إغلاق الخدمة عند التوقف؛ مراجعة أمنية.

## P11 — الاستقرار والإطلاق
**المخرجات:** اختبارات انحدار، RTL/LTR، وصول، أداء، توثيق بناء، APK.
**القبول:** لا عيوب حرجة معروفة؛ توثيق الميزات المكتملة وغير المكتملة؛ إثبات بناء واختبارات.

## قالب التقرير بعد كل مرحلة
- المرحلة ومعرفات FR/NFR.
- الملفات المنشأة والمعدلة.
- القرارات والافتراضات.
- أوامر البناء والاختبار التي نُفذت.
- نتائج فعلية (نجاح/فشل/لم يُشغّل).
- مخاطر أو قيود متبقية.
- الخطوة التالية.
