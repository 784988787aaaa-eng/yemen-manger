# Yemen Manager — موجز المنتج

## الرؤية
إنشاء تطبيق Android محليّ التشغيل لإدارة الملفات وتحليل حزم التطبيقات وتحرير المحتوى الثنائي والنصي، بقدرات واسعة وواجهة خفيفة وسياقية.

## قواعد المنتج
- الاسم: Yemen Manager.
- يعمل جوهر التطبيق دون إنترنت.
- لا حسابات ولا تتبع ولا اتصالات تلقائية.
- الواجهة عربية وإنجليزية مع دعم RTL/LTR حقيقي.
- لا نعرض ميزة على أنها مكتملة إلا إذا نُفذت واختُبرت.
- لا نعدل الملف الأصلي افتراضيًا.
- نعامل الملفات المستوردة كمدخلات غير موثوقة.
- نستخدم واجهات التخزين الرسمية حيث تفرضها قيود Android.
- الأدوات المتقدمة تظهر حسب نوع الملف والسياق؛ لا نحشر كل الأدوات في الشاشة الرئيسية.

## التجربة الأساسية
1. مدير ملفات بلوحتين مستقلتين.
2. عمليات الملفات والبحث والمفضلة وسجل التنقل.
3. معاينة وتحرير النصوص والملفات الثنائية.
4. إدارة الأرشيفات.
5. مختبر APK للقراءة والتحليل أولًا.
6. تعديل الموارد وإعادة البناء والتوقيع ضمن الحدود المدعومة.
7. إدارة التطبيقات المثبتة واستخراج APK وsplit APKs.
8. تكاملات صلاحيات اختيارية، لا افتراضية.
9. بروتوكولات شبكة اختيارية يفعّلها المستخدم يدويًا.
10. إضافات مؤجلة إلى ما بعد استقرار واجهات النواة.

## ما لا نعد به
- لا ضمان وصول إلى Android/data أو Android/obb على كل إصدار.
- لا ضمان لتجاوز كل حماية أو إصلاح كل ملف تالف.
- لا ضمان استعادة المصدر الأصلي أو أسماء obfuscation.
- لا ضمان دمج split APKs في APK واحد صالح.
- لا تثبيت صامت مضمون عبر Shizuku أو Root أو Device Owner.
- لا ادعاءات أداء رقمية دون قياس.

## تعريف المنتج القابل للتسليم
تطبيق حقيقي قابل للبناء والتثبيت، مع وظائف موثقة، واختبارات، وسجل تبعيات وتراخيص، وتعليمات بناء محلية، وتقرير صريح عن حدود الإصدار.
