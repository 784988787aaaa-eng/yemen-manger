# ملاحظات البناء دون إنترنت

1. افحص توفر JDK وAndroid SDK وGradle وAndroid Gradle Plugin وKotlin plugin محليًا.
2. افحص أن جميع dependency artifacts موجودة في Gradle cache أو في مستودع محلي.
3. لا تستخدم أي أمر يفرض تنزيل التبعيات عبر الشبكة.
4. لا تضف مكتبة جديدة إلا بعد إثبات وجودها محليًا أو توثيق أنها blocker.
5. استخدم Gradle offline mode فقط بعد التحقق من أن التبعيات المطلوبة مخزنة محليًا.
6. إن تعذر بناء جزء بسبب dependency مفقود، اعزل الجزء، واستمر في العمل المستقل، واكتب تقريرًا واضحًا.
7. احتفظ بمعلومات إصدارات الأدوات، ونتائج البناء، وتفاصيل التبعيات في docs/.
8. لا تعتبر غياب خطأ من أداة البناء دليلًا على صحة التطبيق؛ شغّل الاختبارات المناسبة.
